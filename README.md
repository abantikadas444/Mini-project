# Interactive Learning Platform

## Project Description

An interactive web-based learning platform that
allows students to access tutorials, take quizzes,
receive feedback, and track their learning progress.

## Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express

Database:
- MySQL

## Features

- User registration and login
- Course management
- Interactive lessons
- Quizzes
- Automatic scoring
- Progress tracking
- Admin management
